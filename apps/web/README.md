# @opusline/web

The Opusline product SPA: Vite + React + TypeScript, TanStack Router
(file-based routes) + TanStack Query. Builds to static files — no SSR, no
server runtime. Talks to the Laravel API through the generated
`@opusline/api-client`, always same-origin (`/api`, `/sanctum`).

```bash
pnpm --filter @opusline/web dev    # Vite on :3000, proxies /api + /sanctum to the API container
pnpm --filter @opusline/web test   # Vitest
pnpm --filter @opusline/web build  # static bundle in dist/
```

`src/routeTree.gen.ts` is generated by TanStack Router — do not edit.
Component stories are served by `apps/storybook`.
